Privacy Policy — sci2real uploader

Effective date: November 3, 2026

sci2real uploader ("the app") is a personal tool used only by the owner of the sci2real YouTube channel to upload that channel's own videos. This policy explains what data the app uses.

YouTube API Services

The app uses YouTube API Services. By using the app you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Data the app accesses

  • The app requests a single OAuth scope, https://www.googleapis.com/auth/youtube.upload, which lets it upload videos to the authorizing account's channel.
  • It does not read channel analytics, comments, subscribers, watch history or any other user data.
  • It does not access data of any YouTube user other than the channel owner who authorizes it.

How data is stored and shared

  • The OAuth token is stored only on the owner's own computer, in a local file readable by that user. It is never sent anywhere except to Google's OAuth and YouTube API endpoints.
  • No data is sold, shared with third parties, or used for advertising.
  • The app does not use cookies or analytics.

Revoking access

Access can be revoked at any time from the Google account security settings at myaccount.google.com/permissions. Deleting the local token file removes the app's stored credentials.

Contact

Questions about this policy can be raised at github.com/OkYongChoi/sci2real-uploader/issues.
