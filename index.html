sci2real uploader

sci2real uploader is a personal automation tool run by the owner of the sci2real YouTube channel. Once a day it builds a short English video that introduces the repositories trending on GitHub that day, and uploads it to the owner's own channel through the YouTube Data API.

What it does

  • Reads the public GitHub Trending page and each repository's public README.
  • Generates a 1080×1920 video with narration and motion graphics.
  • Uploads that video to the sci2real channel with the youtube.upload scope.

It is not offered to other users. It does not read, collect or store data about any YouTube user other than the channel owner.
